    Why this directory exists

    Searching for chocolate nearby usually returns a map full of pins with no way to compare them. We pull public business data for every chocolate shop, chocolatier and candy store we can find, rank each state and city, and show the details you need in one place.

    When a detail is missing, we say so instead of guessing. Read more about how the directory works.
